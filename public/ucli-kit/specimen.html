Code and callouts

Body text is set in Source Serif 4 at a 68 character measure. Inline code such as ucli build gits sits level with the text, and a long path such as ~/.local/share/ucli/tools/mdtexpdf/templates/technical/default.tex wraps instead of clipping. Press Ctrl+C to copy a selection.

A smaller block

Callouts

Note

A neutral aside, set on sunken paper with a grey rule.

Tip

Something that works well, marked in green.

Warning

A thing to watch, marked in amber.

Danger

Something that can lose work, marked in the rubric red.
