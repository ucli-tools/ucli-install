Start with these tools

  • gits

    Work with many git repositories at once.

    ucli build gits
  • mdaudiobook

    Turn markdown into an audiobook.

    ucli build mdaudiobook
  • docx2md

    Convert Word documents to markdown.

    ucli build docx2md
  • ucli

    The installer and updater for the rest.

    ucli update

More tools are listed in the registry.

How updates reach you

  1. A new commitA tool gets a new commit on main.
  2. A pull requestThe registry moves the tool's pin.
  3. A mergeA maintainer merges it.
  4. You updateYou run ucli update.
